# Changelog

## v0.2.0
- Picks photos for what is playing: offers context images (Viboplr's Now Playing Photos and cue sheets), the artist's editorial photos ranked by how close each was taken to the song's year. When few are from that era, one more search adds the year. Still links only, each credited to its photographer. The artist tab and context images share one search per hour. Viboplr versions without context images keep reading the tab's photos.

## v0.1.0
- First release: a Getty Images tab on artist pages (editorial photos as links, each opening on Getty Images) and a read-only `search_photos` tool for AI assistants.
